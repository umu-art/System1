# platform

Технический скелет ядра: API-шлюз, пользователи, диспетчер, знания, диалоги, шлюз каналов, LLM-шлюз. Владелец — Пётр. Go.

Сейчас здесь один сервис-шаблон `s1-dialogs`. Один `go.mod` на все сервисы группы; сгенерированный из контракта код подключается через `replace`.

```bash
python ../../api/build.py --langs go
go run ./s1-dialogs
curl localhost:8080/api/dialogs/info
```

Переменные: `PORT` (по умолчанию 8080), `S1_ENV` (по умолчанию `local`).
