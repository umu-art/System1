# ui

Веб-приложение автора и сотрудника: сценарии, диалоги, заказы, аналитика. Владелец — Павел. React, TypeScript, Vite.

Клиент API генерируется из всех контрактов `api/src` в пакет `s1-ui-api` и подключается как локальная зависимость из `api/build`. В образ уходит собранная статика, её раздаёт nginx (`iac/images/s1-ui`).

```bash
python ../../api/build.py --langs ts
npm ci
npm run dev
```

Запросы на `/api` дев-сервер проксирует на `localhost:8080`.
