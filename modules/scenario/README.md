# scenario

Сценарная машина: движок workflow, агент, валидатор сценариев, продажи, исполнитель задач, коннекторы. Владелец — Александр. Go.

Сейчас здесь один сервис-шаблон `s1-workflow`. Один `go.mod` на все сервисы группы; сгенерированный из контракта код подключается через `replace`.

```bash
python ../../api/build.py --langs go
go run ./s1-workflow
curl localhost:8080/api/workflow/info
```

Переменные: `PORT` (по умолчанию 8080), `S1_ENV` (по умолчанию `local`).
