# System1

No-code платформа для создания, запуска и развития диалоговых сервисов с AI-агентами. Платформа позволяет на основе бизнес-требований формировать исполняемые сценарии с помощью AI-ассистента, подключать внешние системы, управлять работой сервисов и анализировать их эффективность.

## Зачем

Написать код чат-бота сейчас просто. Бизнесу же нужен не код, а работающий процесс: бот, который принимает заказы, записывает, напоминает, передаёт сложное человеку, а потом показывает, где теряет клиентов, и помогает это исправить.

Технически такие сервисы устроены одинаково: жёсткие шаги workflow плюс агент на гибких участках. System1 — одно ядро для всех них. Каждый новый рынок использует его по-своему и добавляет в него функциональность, а конечные продукты для пользователей остаются разными.
