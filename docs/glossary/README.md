# Словарь System1

Каждый термин — отдельный JSON-файл в `terms/`; статусы, разделы и ответственные — в `meta.json`.

## Редактирование

```bash
python3 docs/glossary/serve.py
```

Откройте <http://127.0.0.1:8000> и правьте текст прямо на странице, щёлкнув по нему. Изменения сразу записываются в `terms/*.json` и `meta.json`.
После правок — обычный коммит и PR.

- Нужен только Python 3, без зависимостей.
- Другой порт: `python3 docs/glossary/serve.py --port 8080`

## Экспорт в Markdown

Кнопка «Экспорт MD» в верхней панели → выберите «中文» или «Русский». Скачается `System1-glossary-zh.md` или `System1-glossary-ru.md`: по таблице на раздел, в каждой строке — термин, английское имя и описание на выбранном языке. Экспортируются все термины, фильтры и поиск не учитываются.

## Разделы

Разделы перечислены в панели слева; рядом с каждым — число терминов.

- Щелчок по разделу показывает только его термины, «Все» — все.
- ✎ рядом с разделом — переименовать (название на текущем языке страницы).
- × — удалить. Удалить можно только пустой раздел: сначала перенесите термины в другой.
- «+ Новый раздел» внизу: введите английское имя, из него получится id раздела.

## Формат файла

```json
{
  "group": "channels",
  "order": 2,
  "owner": "petr",
  "status": "prop",
  "ru": "Подключение канала",
  "en": "channel_connection",
  "zh": "渠道接入",
  "def": { "zh": "…", "ru": "…" },
  "ex":  { "zh": "…", "ru": "…" },
  "conflicts": ["любой текст"]
}
```

- Имя файла — id термина, и он повторяет английское имя: `service_spec` → `service-spec.json` (строчные латинские буквы, цифры, `-`). Если поменять английское имя в редакторе, файл переименуется сам; если такое имя уже занято другим термином, изменение не сохранится. При ручной правке JSON переименуйте файл сами.
- Допустимые значения `status`, `group`, `owner` — в `meta.json`. Новых людей добавляйте прямо в `meta.json`.
- Текст в обратных кавычках показывается как код: `` `state.is_generating` ``.
